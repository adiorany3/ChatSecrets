# ChatSecrets Hacker Terminal

Versi ini sudah diperbarui:
- Room yang dihancurkan langsung menghapus data chat dan status online.
- Nama room terkunci sementara 10 menit.
- Setelah 10 menit, nama room otomatis bisa digunakan kembali.
- Catatan pada destroyed_rooms.json otomatis dibersihkan agar tidak meninggalkan jejak.

Jalankan aplikasi:
```bash
pip install -r requirements.txt
streamlit run app.py
```
